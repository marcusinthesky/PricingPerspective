# Reproduction source

The repository contains the analyses, formal results, manuscript sources and
paper website for the four retained papers.

- `python/`: the analysis pipeline, operating-game simulation and shared runtime.
- `lean/`: compiled mathematical results and publication claim certification.
- `latex/`: the four arXiv manuscripts, generated exhibits and source bundles.
- `typescript/`: the website and its paper pages.

Run the commands in the root README from the pinned devenv or Nix environment.
