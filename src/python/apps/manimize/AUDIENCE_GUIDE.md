# Audience guide

The same scene set can be rearranged for different journal and seminar audiences.

## Quantitative Finance

Recommended core sequence: **02 → 03 → 04 → 05 → 09 → 10 → 11 → 12 → 13**.

Emphasize coupling optimization, Hilbert polarization, the distinction between pairwise and coherent multi-marginal constructions, the sharp-versus-relaxed certificate, and the conditional-negative-definiteness test. Scenes 01 and 06–08 can be used as representation and application context.

## Journal of Financial Econometrics

Recommended core sequence: **01 → 02 → 06 → 07 → 08 → 13**, followed by **05** as an identification boundary.

Emphasize that the interaction matrix is constructed upstream from distribution-valued data; target-anchored reconstruction is not a distance kernel; symmetric pairwise geometry can create a directed row-stochastic operator; and the spatial coefficient's adjustment interpretation is conditional on the quadratic exposure model and return bridge.

## European Journal of Finance

Recommended core sequence: **01 → 02 → 03 → 04 → 06 → 07 → 11 → 13**.

Begin with economic intuition and delay functional-analysis terminology. The key narrative is that heterogeneous firm information is retained as a distribution, transport measures the least rearrangement between firms, geometry restricts rather than estimates covariance, peer combinations can jointly reconstruct a target, and observable separation can certify part of portfolio diversification without becoming an expected-return signal.

## Suggested talk lengths

- **Five-minute overview:** 01, 03, 06, 09, 11, 13.
- **Fifteen-minute methods presentation:** all scenes except 12, with brief transitions.
- **Thirty-minute technical presentation:** all thirteen scenes, pausing after 04, 08, and 11 for assumptions and identification boundaries.
